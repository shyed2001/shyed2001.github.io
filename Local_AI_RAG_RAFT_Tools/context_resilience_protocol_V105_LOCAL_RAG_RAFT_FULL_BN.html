১. ভূমিকা

Context বড় হলে token cost, retrieval difficulty, latency, DOM pressure ও instruction drift বাড়ে। তাই পুরো transcript নয়, compact state migration দরকার।

২. প্রযুক্তিগত সীমা

Transformer attention pairwise token interaction তৈরি করে; practical cost KV cache, batching, hardware, kernel, quantization ও serving design দ্বারা নির্ধারিত।

৩. Tokenization প্রক্রিয়া

Token counting model-specific। OpenAI, Claude, Llama ও local runtime আলাদা tokenization ব্যবহার করে।

৪. Serialization Format

Markdown human handoff-এর জন্য; YAML config-এর জন্য; JSONL event/evidence log-এর জন্য; JSON strict API-এর জন্য; TOON emerging compact payload।

৫. Context Compression

Compression মানে load-bearing facts রাখা এবং filler, duplicated explanation, raw logs বাদ দেওয়া।

৬. Automated Ingestion Pipeline

Handoff files vector RAG, GraphRAG, Graphify, MemPalace এবং local index-এ ingest করা যায়।

৭. Symbolic Compression ও Sparse Priming

SPR dense trigger হিসেবে কাজ করে, কিন্তু formal evidence-এর বদলে ব্যবহার করা যাবে না।

৮. Persistent State Machine

PROJECT-SPEC stable rules রাখে; SESSION-HANDOVER current state; FAILED-PATHS negative memory; DECISIONS rationale; EVIDENCE-LOG proof pointer।
